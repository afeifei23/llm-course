# 大模型入门课 · 从零开始用 DeepSeek Harness 干活

一门给完全没接触过大模型的成年人准备的入门课。不用写代码，每章 5–8 分钟，学完能独立完成一次**文档补全**和一次**文档比对**。

**在线地址**：https://afeifei23.github.io/llm-course/

## 怎么打开

在线直接访问上面的地址；也可以把仓库下载下来，双击 `index.html` 离线打开（Chrome / Edge / Safari 都行），不需要联网，也不需要安装任何东西。

- 用键盘 `←` `→` 翻页，或 `空格` 下一页
- 按 `N` 显示讲师讲稿，按 `O` 看全部 48 页总览
- 按 `F` 全屏，按 `?` 查看全部快捷键
- 小测页点一下选项就会显示答案
- 想导出 PDF：`Cmd/Ctrl + P`，纸张选横向、边距选“无”，即可一页一张

仓库里同时附了一份导出好的 `slides.pdf`（48 页，16:9），可以直接发给别人或打印。

## 怎么改内容

1. 用文本编辑器打开 `slides.js`，每一页是一个对象：`layout`（页面类型）、`chapter`（顶部标签）、`title`（总览标题）、`html`（页面内容）、`notes`（讲稿）。
2. 改文案直接改 `html` 里的中文；加一页就复制一个对象、改内容，页数会自动更新。
3. 配色、字号、间距都在 `styles.css` 顶部的 `:root` 变量里，改一处全局生效。
4. 不需要构建、不需要装依赖，改完刷新浏览器即可看到效果。

## 设计说明

- 16:9 固定画布（1280×720），自动等比适配任何屏幕，所以版式在投影、笔记本、平板上都一致。
- 主色是暖纸色 + 砖橙强调色，深色只用在章节扉页，形成呼吸节奏。
- 全部图表用内联 SVG / CSS 绘制，没有外部图片依赖，断网也能讲。
- 命令、提示词统一用等宽字体卡片呈现，方便学员“照着抄”。

## 内容依据

课程里提到的 DeepSeek Harness 命令与用法，均按本机安装的 `@deepseek-ai/dsh`（v0.2.1）核对：

- 启动方式：`dsh web`、`dsh headless "任务"`、`dsh <profile>`
- 斜杠命令：`/plan`、`/plan off`、`/compact`、`/goal`、`/feedback`
- 工作区规则：在哪个目录启动，哪里就是默认工作区

如果后续版本命令有变化，改 `slides.js` 第 30、31 页即可。
